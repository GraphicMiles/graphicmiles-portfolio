Design Decisions

  • No tabs. Continuous scroll. All content accessible by scrolling.
  • No card gallery. Projects are full-width editorial blocks.
  • One typeface. Inter only. Hierarchy through weight + size + spacing.
  • No yellow. The aggressive background color is removed.
  • No pill tags. Technology shown as simple inline metadata.
  • No modals. Project details are inline, in the page flow.
  • No "Ready for work" badge. Availability from contact placement.
  • Generous whitespace. Sections breathe. Editorial rhythm.
  • Off-white bg. Softer than pure white. Less clinical.
  • Muted green accent. Connects to existing brand without being aggressive.

  • Meta: 0.75rem / 500 / 0.06em / uppercase

What's removed

  • Tab navigation (Work/Services/About)
  • Card-based project gallery
  • Service listing section
  • Yellow background on About
  • "Ready for work" notice card
  • Avatar lightbox
  • Project detail modals
  • Space Grotesk font
  • Font Awesome icons
  • Pill-shaped tags
  • Cover banner ("Web development / AI automation")

Mobile behavior

  • Single column throughout
  • Project images full-width above text
  • Navigation simplified to name + hamburger
  • Generous section spacing preserved
  • Touch targets min 44px
