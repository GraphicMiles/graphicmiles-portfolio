Projects

  • Legally Unbullied

    A Nigerian legal information assistant that answers from statute and shows its source.

    I built the assistant and the pipeline behind it. It classifies a question, retrieves the relevant provisions from a Nigerian statutory corpus, and drafts an answer with each claim tied to a provision. Every citation is checked token by token against the retrieved text, and a critic stage refuses the answer when the support is not there. The hard part was keeping that line while the answer streams: when support is thin, it fails closed instead of sounding confident.

    Node.js, Express, Firebase, Gemini. 100 authored scenarios run through the evaluation gate.

    Live demo Code

  • Scout

    A browser automation runtime in Rust that runs without a browser install.

    I wrote Scout as one small binary. It fetches a page, parses the DOM, runs page JavaScript in a sandbox, fills forms and returns structured data. The same tools are exposed over an authenticated HTTP API and an MCP server, so an agent can drive it. The hard part was memory: a headless browser costs hundreds of megabytes, and Scout had to stay small enough to run beside the app that calls it.

    Rust, MCP over stdio, published as @graphicmiles/scout. Idles around 5 MB.

    Docs Code

  • Nearspace

    A creator network for Nigeria, built around who is nearby.

    I built it end to end. It maps creators near you, carries one-to-one and group chat, and sells a Pro tier through Paystack. Presence runs on Firebase Realtime Database while reads are cache-first, and the app installs as a PWA so it opens on a weak connection. The hard part was doing proximity without a server of my own, so location checks, security rules and every write go through Firebase and Vercel functions.

    React, Vite, Firebase, Vercel functions. 590+ tests across unit, API and rules suites.

    Live demo Code

  • Luna

    An Android agent that runs the language model on the phone.

    I built Luna as a Flutter app over a Java device layer, with llama.cpp loaded through JNI so GGUF models run locally with no network call. It streams tokens as they are generated, checks every model file against a checksum before loading, and keeps a small agent core that decides when to reach for a tool. The hard part was the bridge: memory ceilings, heat, and a 4-bit model that has to answer before the phone decides the app has stalled.

    Flutter, Java, JNI, llama.cpp. 42 tests on the agent core, with an optional cloud control plane.
