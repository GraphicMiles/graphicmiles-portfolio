Five things I built

  • Legally Unbullied

    A Nigerian legal assistant that answers from statute and cites the section it used.

    It takes a question in plain English and sorts it into one of twenty practice areas. Then it pulls the matching provisions from a Nigerian law corpus in Firestore and drafts an answer with every claim tied to a section. Each citation is checked against the retrieved text, and a critic stage refuses the answer when support is missing.

    Node.js, Express, Firebase, Groq and Gemini. 100 test scenarios run through the evaluation gate.

    Live app Code

  • Scout

    A browser automation runtime in Rust, small enough to sit beside the app that calls it.

    It loads a page, runs its JavaScript in a sandbox, fills forms and returns structured fields. The same tools are served over an HTTP API and an MCP server, so an agent can drive it. The hard part was memory: a headless browser costs hundreds of megabytes and this had to idle near five.

    Rust, HTTP API, MCP over stdio, published on npm as @graphicmiles/scout. Idles around 5 MB.

    Docs Code

  • Nearspace

    A community and discovery app for finding tech creators near you, live in Nigeria.

    Geohash proximity puts nearby creators on a live map, with one-to-one and group chat and a Pro tier through Paystack. Presence runs on Firebase Realtime Database while reads stay cache-first, and it installs as an offline-tolerant PWA. Every write goes through verified Firebase rules or a serverless function.

    React, Vite, Firebase, MapLibre, Paystack, Vercel. 590+ tests across unit, API and security-rules suites.

    Live app Private repository

  • Luna

    An Android coding and utility agent that runs the language model on the phone.

    llama.cpp is loaded over JNI, so quantised GGUF models run on the device with no network call, streaming tokens as they arrive. Model files are verified by SHA-256 checksum before loading, and a bounded agent core gates write actions behind approval with one-tap undo.

    Flutter (Dart), Java, JNI, llama.cpp. 42 agent-core tests, and an optional cloud tier measured at 49 tok/s.

    Technical report Public build

  • Atelier Drop

    A streetwear storefront rebuilt from the outside, one measurement at a time.

    18 static pages covering the home template, the collection, nine product pages, the bag, search and four concept pages. The catenary rail, the runway, the shoe shelf and the story viewer all run on plain JavaScript. Every page was diffed against the live build at desktop and mobile widths until the gaps closed to a few pixels.

    HTML, CSS, vanilla JS. 27/27 click paths and 36 page audits pass; page heights within 0 to 19 px of live.
