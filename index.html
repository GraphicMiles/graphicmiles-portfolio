CAREER

Experiences

What I have built, most recent first

At Scout, I built a browser-automation runtime in Rust for developers and AI agents who need the web without carrying Chromium around.

Key Contributions and Accomplishments:

  • One small binary that idles around 5 MB and starts in milliseconds. Install it from npm as @graphicmiles/scout, or build it from source with Cargo.
  • Fetches pages, runs page JavaScript in a sandbox, follows script and meta-refresh navigations, and keeps cookies and history per session.
  • Clicks, fills, selects and submits forms, including multipart forms and file uploads, and extracts typed text, URLs, numbers, prices and dates.
  • Exposes the same tools over an authenticated HTTP API and as an MCP server, so MCP clients can drive it directly.

At MotionShelf, I built a library of copyable first-party UI examples and offline developer tools, with selected links to upstream open-source projects.

Key Contributions and Accomplishments:

  • Every resource can be previewed live before you copy the source, a setup command, or download the files.
  • The interactions collection ships each example for vanilla JavaScript, React, Vue and Svelte.
  • Contributions are reviewed before anything is published: uploaded code is inspected as data, never executed, and nothing goes live automatically.
  • First-party MotionShelf code is MIT-licensed.

At Nearspace, I built a location-based creator community for finding nearby builders and professionals. It has production users and a private codebase. Case study on request.

Key Contributions and Accomplishments:

  • Geohash-proximity discovery with RTDB presence, so nearby creators surface in real time.
  • Cache-first Firestore reads to keep the feed fast and cheap.
  • 590+ unit tests behind a strict verify pipeline. Tests are part of the feature, not a follow-up task.
  • A live map, nearby discovery and a builder feed that turn online connections into real-world collaboration.

At ForgeAI, I built a local-first AI coding assistant for Android. No server required. The model runs on the phone itself.

Key Contributions and Accomplishments:

  • GGUF models run natively through a llama.cpp, JNI and Capacitor bridge.
  • Incremental token streaming, so answers arrive as they are generated.
  • A checksummed, immutable model catalog, so you know exactly what you downloaded.
  • A 42-test agent core covering the on-device loop.

At ODG Deliveries, I built food delivery for Ibadan around reviewed kitchens.

Key Contributions and Accomplishments:

  • One platform with four roles (customers, kitchens, riders and admin) on a single Postgres database and Express API.
  • Reviewed kitchens first: quality is curated before it is listed.
  • Designed end to end, from the ordering flow to the rider and admin views.

ABOUT

My Philosophy

I’m Raji Adewunmi Farouq, Graphic Miles, a developer and builder from Lagos. I’ve been in tech since 2021, back when I was in secondary school. I started out building websites and designing content: YouTube thumbnails, flyers and print. These days I build and ship my own products.

I care about details many people skip: hover states, spacing and load times. They separate “it works” from “it feels considered.” Tests are part of the feature, not a follow-up task, and bundle budgets are a design constraint, not an afterthought.

I am open to frontend builds, product interfaces, AI automation and backend integrations. If you have a product to build or an interface to improve, email me at rfarouq69@gmail.com.
